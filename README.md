# Portfolio Sith

Portfólio de Gustavo Martins França. Next.js (App Router) + TypeScript + Tailwind, exportado como site estático.

## Rodar

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # lógica pura (Vitest)
npm run build    # gera out/
```

## Editar conteúdo

Tudo em `src/data/*.ts` (perfil, projetos, skills, experiência). O layout não muda.

O restante do guia (placeholders, áudio, deploy) está na seção final, preenchida na conclusão do projeto.
