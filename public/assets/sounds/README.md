# Sons

- `emperor-theme.mp3`: trilha ambiente (tema do Imperador, John Williams, Lucasfilm/Disney, compilação de fã). É tocada em volume baixo (`MUSIC_VOLUME` em `src/lib/audio.ts`). Se for publicar comercialmente, troque por uma faixa livre de direitos e ajuste `MUSIC_SRC`.
- `saber-on.mp3`, `saber-hum.mp3`, `saber-swing.mp3`, `blip.mp3`: opcionais. Se ausentes, o site sintetiza os efeitos com Web Audio API.
- Sugestão de fonte livre: freesound.org (filtre por licença CC0).
- `ignition.mp3`: som de ignição do sabre, usado ao aceitar na tela de entrada (e no easter egg do Konami). Veio da pasta do Claude Design (`freesound_community-lightsaber3-87667`). **Confira a licença de uso antes de publicar** (é um som da comunidade Freesound/Pixabay). Se o arquivo faltar ou falhar, o site usa um som sintetizado.
